# Project Statement

## Punctuation Corrector

### Problem Statement

People often make small punctuation mistakes while typing, such as adding extra spaces before punctuation marks, missing spaces after punctuation, using repeated punctuation like `???` or `!!!`, or forgetting to end a sentence with a full stop.

The aim of this project is to create a simple Python program that helps identify and correct these common mistakes.

### Objective

* Correct basic punctuation errors.
* Improve sentence formatting.
* Count punctuation marks in a sentence.
* Save corrected text for later use.

### Expected Output

The program should take a sentence as input, make the necessary corrections, and display the corrected sentence. It should also allow the user to save and view corrected text using a text file.
