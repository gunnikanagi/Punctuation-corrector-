# Punctuation Corrector

## About This Project

This is a simple Python project that I made to practice what I learned in Python Essentials. The idea was to create a program that can fix common punctuation mistakes and make a sentence easier to read.

The program can correct punctuation, count punctuation marks, check if a sentence ends properly, and save the corrected text so it can be viewed later.

## Features

* Removes spaces before punctuation marks.
* Adds spaces after punctuation where needed.
* Removes repeated punctuation like `???` and `!!!`.
* Capitalizes the first letter of a sentence.
* Adds a full stop if a sentence does not end with punctuation.
* Counts punctuation marks in a sentence.
* Saves corrected text.
* Lets you view or clear the saved text.

## Project Files

* `main.py` – Runs the program and shows the menu.
* `punctuation.py` – Handles punctuation and spacing corrections.
* `text_check.py` – Checks the sentence and counts punctuation marks.
* `file_handler.py` – Saves, views, and clears text.
* `corrected_text.txt` – Stores the saved corrected sentences.

## How to Run

1. Open the project folder.
2. Run the program using:

```bash
python3 main.py
```

3. Choose an option from the menu and enter your sentence.

## Example

Input

`hello ,how are you???`

Output

`Hello, how are you?`
